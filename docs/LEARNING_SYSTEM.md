# TRADECRAFT Learning System Architecture

## Gameplay-First Learning

Financial concepts in TRADECRAFT are integrated into interactive 3D gameplay:

1. **Market Fundamentals:** Order books, bid/ask spread, virtual capital.
2. **Macro Events:** Oil supply shocks, inflation, sector correlation.
3. **Risk Engineering:** Max drawdown, position sizing limits, Sharpe ratio.
4. **Trading Psychology:** Emotional control, revenge trading detection.
